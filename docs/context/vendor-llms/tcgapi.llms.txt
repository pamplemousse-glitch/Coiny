# TCG API

> Pricing API for 89+ trading card games with prices refreshed daily for major games (Pokemon, Magic, Yu-Gi-Oh, Lorcana, Flesh and Blood, One Piece, Riftbound) and every 3 days catalog-wide, plus per-condition prices and price history. Covers games (Pokemon, Magic: The Gathering, Yu-Gi-Oh!, Lorcana, Flesh and Blood, One Piece, Riftbound, and more) sourced from TCGPlayer. Free tier 100 requests/day, paid tiers $9.99–$99.99/mo, plus x402 pay-per-request in USDC on Base or Solana.

Base URL: `https://api.tcgapi.dev/v1`. Authentication is either an `X-API-Key` (instant signup, no approval) or x402 USDC pay-per-request — same endpoints, agent picks. For full machine-readable reference of every endpoint, see [llms-full.txt](https://tcgapi.dev/llms-full.txt).

## API Reference

- [Games](https://tcgapi.dev/api/games/): List the 89+ supported games and per-game metadata
- [Sets](https://tcgapi.dev/api/sets/): List sets, fetch set details, list cards in a set
- [Cards](https://tcgapi.dev/api/cards/): Card details, prices per printing, per-condition prices (NM/LP/MP/HP/Damaged), history, TCGPlayer-ID lookup
- [Search](https://tcgapi.dev/api/search/): Cross-game card and sealed-product search with filters
- [Prices](https://tcgapi.dev/api/prices/): Top movers and bulk price endpoints
- [Bulk](https://tcgapi.dev/api/bulk/): Bulk prices, per-condition prices, cards, history, plus name and TCGPlayer-ID resolve
- [OpenAPI spec](https://tcgapi.dev/openapi.yaml): Source-of-truth machine-readable spec
