# Zerion API

> Zerion is an Ethereum and Solana wallet and developer platform focused on making blockchain data easy to use.

## Docs

- [Introduction to the Zerion API](https://developers.zerion.io/introduction.md): Zerion API is a REST API for onchain wallet data: portfolios, DeFi positions, NFTs, transactions, PnL, prices, and swaps across EVM chains and Solana.
- [Quickstart](https://developers.zerion.io/quickstart.md): Get a Zerion API key from the Dashboard and make your first authenticated request for wallet portfolio data in under 5 minutes with curl, JavaScript, or Python.
- [Authentication](https://developers.zerion.io/authentication.md): Authenticate Zerion API requests with an API key using HTTP Basic Auth, including header format, environments, and code samples in curl, JavaScript, and Python.

- [Zerion CLI and agent skills for AI coding tools](https://developers.zerion.io/build-with-ai/zerion-cli.md): Analyze wallets, sign, swap, and bridge across EVM chains and Solana from the command line, plus agent skills that ship across every major AI coding agent.
- [x402 payments: pay-per-request Zerion API access](https://developers.zerion.io/build-with-ai/x402.md): Call the Zerion API without an API key by paying per request in USDC on Base or Solana with the x402 protocol. No signup, rate limits, or monthly plan needed.
